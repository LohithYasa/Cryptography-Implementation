# Cryptography Implementation - Internship Project

## Project Title
Cryptography Algorithms Implementation

## Objective
To implement common cryptography algorithms and security utilities using a web-based Python Flask application.

## Features
- Caesar Cipher encryption and decryption
- Vigenere Cipher encryption and decryption
- XOR encryption and decryption
- Base64 encoding and decoding
- MD5, SHA1, SHA256, SHA512 text hashing
- File hash generation
- Password strength checker
- Secure password generator
- Downloadable project report
- Professional responsive UI

## Tools Used
- Python
- Flask
- HTML
- CSS
- Hashlib
- Base64

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
